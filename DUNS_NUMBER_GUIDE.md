# DUNS Number Guide for Apple Developer Account

## What is DUNS?

**DUNS** = Data Universal Numbering System  
**Issued by**: Dun & Bradstreet (D&B)  
**Purpose**: Business identification number (like business ID)  
**Required for**: Organization Apple Developer accounts

---

## Do You Actually Need It?

### Check First
When converting account to "Organization," Apple asks for:
- [ ] Legal organization name (GCC TBC)
- [ ] Tax ID (if available)
- [ ] Address
- [ ] Contact person

**DUNS may be optional** if you provide:
- ✅ Tax ID (TIN/EIN for US organizations)
- ✅ Registration documents
- ✅ Proof of organization status

### If GCC TBC is a School
Schools often have:
- ✅ Tax ID (EIN if non-profit)
- ✅ School registration
- ✅ District/Board approval

**You may NOT need DUNS.**

---

## How to Get DUNS Number (If Needed)

### Option 1: Online (Fastest - Free)
1. Go: [dnb.com/get-duns](https://dnb.com/get-duns)
2. Click: "Get a DUNS Number"
3. Fill form:
   - Organization name: GCC TBC
   - Address: School/office address
   - Contact: Principal/administrator
4. Submit
5. **Result**: DUNS issued instantly or within 2-5 days (free)

### Option 2: Phone (If Urgent)
1. Call: 1-800-234-3867 (Dun & Bradstreet)
2. Say: "I need a DUNS number for my organization"
3. Provide info:
   - Organization name
   - Address
   - Contact person
4. **Result**: DUNS issued within 1-2 days

### Option 3: Apple's Process
1. Start Apple account conversion
2. Apple will ask for verification
3. Apple may contact D&B for you
4. D&B issues DUNS
5. **Result**: Takes 5-10 days

---

## Information You'll Need to Provide

To get DUNS, have ready:

- [ ] **Organization legal name**: "GCC TBC" (exact legal name)
- [ ] **Address**: School/office physical address
- [ ] **Contact person**: Principal, director, or administrator name
- [ ] **Email**: Contact email
- [ ] **Phone**: Contact phone number
- [ ] **Business type**: "Educational Institution" or "School"
- [ ] **Employees**: Approximate number of employees
- [ ] **Tax ID** (optional): EIN if you have it

## Cheaper Alternatives

### If GCC TBC is a School (Non-profit)

You may have **Tax ID instead of DUNS**:

```
Non-profit school → Has EIN (Employer Identification Number)
Similar to: XX-XXXXXXX (format)

Apple often accepts:
✅ EIN (Tax ID)
✅ School registration number
✅ District/Board registration

Instead of DUNS
```

**Find GCC TBC's Tax ID:**
1. Ask principal/administrator
2. Check school website
3. Check budget documents
4. Check IRS letter granting non-profit status

If you have EIN/Tax ID → **You probably don't need DUNS**

## What to Tell Apple

When converting account, provide:

### If You HAVE Tax ID (EIN)
```
Account Type: Organization
Organization Legal Name: GCC TBC
Tax ID (EIN): XX-XXXXXXX
Address: [school address]
Authorized by: [Principal name]
```

Apple will likely accept this **without DUNS**.

### If You DON'T Have Tax ID
```
Account Type: Organization
Organization Legal Name: GCC TBC
DUNS Number: [Number from D&B]
Address: [school address]
Authorized by: [Principal name]
```

### If You Have Both
```
Provide both (stronger application)
```
