⚙️ Technical Details

Architecture

Face Detection: RetinaFace
Embeddings: ArcFace (512-D)
Matching: Cosine Similarity + MAX from 3 angles
Vector DB: FAISS (IndexFlatL2)
Face Alignment: InsightFace (built-in)

Performance

Face Detection: 50-100ms
ArcFace Embedding: 150-300ms
Vector Search: 10-50ms
Total Attendance: < 2 seconds
